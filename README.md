FAR: LONE SAILS VR  -  VR mod (Unity 2019.1.7f1, IL2CPP x64, built-in renderer, BepInEx 6)
=====================================================================================
Version 0.1.5 (test build)

Install
-
unzip to game folder, only tested with virtual desktop XR

VIEW
  * THIRD PERSON (default): you stand where the game's side-view camera is and see the world like a diorama, in 3D.
    RIGHT STICK UP / DOWN = move your view forward / back (closer to / further from the scene).
  * FIRST PERSON: you are the character - look around freely. The left stick walks where you look.
  * CLICK R3 (right stick) = switch 1st / 3rd person (outside play: re-centre).
  * Menus / pause: the game's picture on a big screen in front of you.

CONTROLS WITH VR CONTROLLERS (they act as an Xbox gamepad - the game's own gamepad controls)
-
  Left stick ........... move  
  
  Right stick ...... 3rd person: up / down = view forward / back
  
  Click R3 ............. 1st / 3rd person
  
  X + Y together ... Start (pause)
  
  A + B together ....... Back
  
  BOTH stick clicks .... click = re-centre;  HOLD 1 s = VR settings menu
                         (stick up / down = choose, left / right = change, A = switch, B = close)

XBOX CONTROLLER
  Click R3 = 1st / 3rd person; L3 + R3 = re-centre, hold 1 s = VR settings; 3rd person right stick up / down = zoom.

Disable: to disable Mod rename winhttp.dll to winhttp.dll.bak
